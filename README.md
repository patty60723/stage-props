# 舞台道具排列

給歌唱班同學在舞台上排列道具的單頁網頁。純 HTML/CSS/JS，資料存在 Firebase Firestore（見 SETUP.md）。

## 功能
- **事件** ＝ 呈現日期 ＋ 舞台，可無限新增、複製（沿用上次排法）。
- **道具庫**：全域共用，同一道具可跨事件重複使用、同場放多個。類別：劇場提供／個人提供／演員。
- **舞台規格**：自訂場地寬×深（公尺），可新增、編輯。
- **排列舞台**：俯視圖拖曳、方向鍵微調、旋轉、複製。
- **輸出**：全部或個人（或劇場）的道具清單＋俯視圖；列印／PDF、PNG、CSV；可「每人一頁」。

## 全班共用
設定 Firebase 後（見 [SETUP.md](SETUP.md)），同學輸入同一組班級代碼即可共同新增、編輯並即時同步；也可按「分享連結」直接把代碼帶給同學。未設定時為單機模式。

## 發佈新版
每次推上去前執行 `bash tools/bump-version.sh`，更新 `index.html`／`app.js` 等載入檔案的版本號（`?v=…`），瀏覽器才不會用到舊快取。

## 測試版（beta）
`beta/` 是一份完整的模擬版：功能和正式版相同，另外加入尚在試用的新功能（劇場道具庫依場地分組、演員進場帶道具、保留空場景、手機版輸出排版）。
資料只存在瀏覽器（獨立的儲存空間，不會連到 Firebase，也不會動到正式資料），可用頁面上方的「重置範例資料」還原。
